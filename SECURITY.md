# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.7.x   | Yes       |
| < 0.7   | No        |

Only the latest 0.7.x release of each `@paragraf/*` package receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue or pull request for a security problem.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**, or go directly to
<https://github.com/kadetr/paragraf/security/advisories/new>.

Include the affected package and version, a description of the problem, and steps or an input file that reproduces it.

This is a small project maintained by one person. I aim to reply within 7 days and will tell you what I plan to do. A fix is released as a new patch version, and the advisory is published once it is available.
